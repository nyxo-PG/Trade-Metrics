📋 Pages & Features Breakdown

1. 🏠 Dashboard (Home)
    Portfolio summary (total P&L, win rate, total trades)
    Daily / Weekly / Monthly performance snapshot
    Recent trades list
    Quick "Add Trade" button
    Performance graph (equity curve)
    Best & worst trade of the period
    Streak tracker (winning/losing streak)


2. 📝 Trade Log (Journal)
    Add new trade form
    Trade list table (filterable & sortable)
    Each trade entry includes:
        Symbol / Ticker
        Date & Time (open/close)
        Direction (Long / Short)
        Entry & Exit price
        Position size / Lot size
        Stop Loss & Take Profit
        P&L (realized)
        Fees / Commission
        Strategy tag
        Emotion tag (calm, fearful, FOMO, confident)
        Notes / Remarks
        Screenshot upload (chart image)


3. 📊 Analytics & Statistics
    Win rate %
    Average win vs average loss
    Risk/Reward ratio
    Profit factor
    Max drawdown
    Best/worst day, week, month
    Trade duration analysis
    Performance by:
        Symbol
        Strategy
        Session (London, NY, Asia)
        Day of week
        Time of day
    Heatmap calendar (green/red days)


4. 🗓️ Calendar View
    Monthly calendar with daily P&L color coding
    Click a day to see all trades that day
    Streak highlights


5. 📁 Playbook / Strategies
    Create & name strategies
    Strategy description & rules
    Entry & exit criteria
    Attach example trades
    Performance stats per strategy


6. 🧠 Trading Journal / Notes
    Daily pre-market notes (plan for the day)
    Post-session review
    Mindset & emotion tracking
    Lessons learned section
    Tag notes by date or trade


7. 💰 Account Management
    Multiple account support (Broker 1, Broker 2, Demo, Live)
    Starting balance input
    Deposit / Withdrawal tracking
    Current balance auto-calculation
    Account equity curve


8. 🎯 Goals & Risk Management
    Daily / Weekly / Monthly profit goal
    Max daily loss limit (kill switch alert)
    Risk per trade setting (% of account)
    Goal progress tracker
    Rule checklist before trading


9. 📤 Import / Export
    CSV import (from broker statements)
    Manual entry
    Broker API integration (MT4/MT5, Binance, etc.)
    Export journal as PDF or Excel
    Backup & restore


10. ⚙️ Settings
    Profile & account info
    Currency preference
    Timezone settings
    Notification preferences
    Theme (dark/light mode)
    Subscription / billing plan


11. 🔔 Notifications / Alerts
    Daily loss limit reached
    Goal achieved
    Weekly recap reminder
    Inactivity reminder


12. 👤 Profile / Leaderboard (optional)
    Public trader profile
    Share trade ideas
    Community leaderboard (opt-in)
    Follow other traders
